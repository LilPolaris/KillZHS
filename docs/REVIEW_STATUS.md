# 第一次审查落实情况

对应最初的 12 项审查意见，更新于 2026-10-17，版本 0.1.0-beta.4。

|编号|状态|当前行为|
|---|---|---|
|1 总时长收尾|已实现|worker 接收截止时间与停止请求；视频循环检查实际经过时间，尝试提交尚未上报的进度。最多给 30 秒收尾，超时强制终止。PPT 的既有 finally 清理可在正常展开时执行，断电、强制终止或网络故障不能保证远端删除成功。|
|2 验证码后继续下一门|已实现|识别到共享课验证码后停止本批次，提示手动验证；可通过通知提醒。未实现验证码自动识别或提交。|
|3 退出清理异常|已实现|清理增加超时处理，异常不阻止后续状态和历史记录处理。等待子进程时释放状态锁。|
|4 坏课程数据|已实现|worker 和主进程均逐条校验，保留正常数据；部分同步不完整时不清空已有课程。|
|5 状态轮询|已实现主要建议|按日志游标传新增日志，历史记录按版本传输；后台标签页降为 5 秒轮询。课程和二维码仍随状态传输。|
|6 DPAPI 加密|未实现|API Key、Cookie、通知密钥仍是本机私密文件；页面不回传密钥。升级暂未改变凭据存储格式。|
|7 锁定依赖|已实现|运行、构建和开发依赖锁定版本；构建校验安装版本。没有承诺 ZIP 字节完全一致。|
|8 许可证自动收集|已实现|按运行依赖及其环境标记、extras 递归收集，附带 inventory.json，替代手写包名清单。|
|9 CSS 合并|未实现|暂未重排现有样式，避免把视觉重构混进运行行为修复。|
|10 重复常量|已实现|默认设置从后端下发；视图标题共用映射。|
|11 启动入口|已实现|标准入口是启动KillZHS.bat；旧名称保留为转发入口，使用相同的桌面启动逻辑。|
|12 CI 检查|已实现|基础 Ruff 检查、JavaScript 语法、离线单测；在隔离演示服务器执行 Playwright 的配置、开始、停止、历史日志查看及下载流程。|

验证使用模拟客户端和隔离用户目录，不改变正在运行的用户实例，也不调用付费模型。
