# KillZHS 0.2.2 · 答案保存诊断与重试恢复

这是测试发布。推荐 Windows 10 / 11 x64 用户下载 `KillZHS-0.2.2-windows-x64-setup.exe`。

- 兼容答案保存与交卷接口的整数 / 字符串成功码，拒绝布尔值、浮点数等不明确格式。官网页面使用宽松相等比较，原实现只接受整数。
- 保存失败时显示题号与返回码，区分答题验证和禁止答题；不公开接口原文、题目、答案或凭据。诊断仅保存在本机答题记录中。
- 保存失败后再次手动启动同一试卷，核对题目编号、题型、选项及考试上下文后，复用本机已生成的完整答案，不重复请求模型。新版记录还校验整份题目与选项文本摘要；兼容 0.2.1 的完整答案记录。
- 记录损坏、题目变化、答案不匹配时停止，不自动覆盖记录或重新请求模型。平台答案读回复核与重复交卷保护继续生效。

本机完整离线测试 **436 项及 8 个子测试通过**，静态检查通过。打包程序的演示启停、历史、真实子进程环境检查和退出通过，中文安装器已编译并校验。测试覆盖字符串成功码、保存拒绝、进程重启后的零请求恢复、旧记录恢复、缓存损坏 / 不匹配和复核失败。

## 已知范围

实际使用中出现过“平台未确认答案保存成功”，旧日志没有保留具体返回码。因此，字符串成功码兼容是已确认的代码差异，尚不能断言它就是这次平台拒绝的原因。本版提供具体诊断，保留已生成答案以便排查；未通过真实账号自动答题或交卷验证。

升级会保留 `%LOCALAPPDATA%\KillZHS\v2` 下的设置、Cookie 和答题记录。安装时仍可选择是否创建桌面快捷方式。进入试卷可能开始计时或消耗答题机会；不会因安装或启动程序而自动开始答题。
