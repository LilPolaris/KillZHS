# KillZHS 0.2.1 · 安装包与自动答题编号修复

这是测试发布。建议 Windows 10 / 11 x64 用户下载 `KillZHS-0.2.1-windows-x64-setup.exe`。

- 新增简体中文安装向导，可选择安装位置和是否创建桌面快捷方式；默认不创建快捷方式，也不自动启动程序。
- 安装到当前用户目录，不需要管理员权限。提供开始菜单和卸载入口，卸载保留账号设置、日志及交卷记录。
- 保留免安装 ZIP，完整解压后运行 `KillZHS.exe`，不要单独移动 exe。
- 修复自动答题读取试卷时对题目 / 选项编号校验过严的问题，原样保留编号中的 `+`、`/`、`=`。不改写答案，不放宽复核与重复交卷保护。
- 完成模块化重构，统一任务子进程通信，补充停止、历史、通知、计划及验证恢复测试。

本机 386 项测试及 8 个子测试通过。安装时两种桌面快捷方式选项、实际安装后的进程环境检查、启停和卸载均已验证；14 个离线协议场景与基准一致。

## 升级

先退出旧程序，再安装新版。旧版免安装目录不会被安装器自动扫描或删除。

新版使用独立的 `%LOCALAPPDATA%\KillZHS\v2` 数据目录，需要重新扫码并配置 AI；不会自动导入旧版 Cookie、密钥或交卷记录。进入试卷可能开始计时或消耗答题机会，模型可能答错；已有交卷记录的试卷应先在官网核对。

本次没有执行真实模型答题、答案保存或交卷。离线验收不能替代平台实际结果，完整说明见仓库 README 和 Windows 使用说明。

下载后可对照 `SHA256SUMS.txt` 检查文件完整性。
