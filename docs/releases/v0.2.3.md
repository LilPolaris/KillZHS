# KillZHS 0.2.3 · 查看测验成绩

这是测试发布。Windows 10 / 11 x64 用户可下载 `KillZHS-0.2.3-windows-x64-setup.exe`。

- “测验与考试”页新增“刷新成绩”，同步平台公布的分数与总分，展示在每份试卷下方。
- 区分待批阅、成绩未公布和真实的 0 分；支持小数与数字字符串。只有平台列表已评分状态的分数会被显示，不把未作答 / 待批阅的默认 0 当成成绩。
- 平台仅返回百分制成绩时明确标注；成绩单位不混用，不自行换算。
- 刷新使用原有的列表同步操作，不需要启用 AI，不进入试卷、启动答题计时、请求模型或交卷。需要有效的登录状态。
- 平台最新的已提交状态优先于过去的本地错误提示。保留答案恢复与重复交卷保护。

提供中文安装包与免安装 ZIP。安装仍可选择是否创建桌面快捷方式，升级保留本机设置、登录凭据和答题记录。请退出旧版后安装，再到“测验与考试”点击“刷新成绩”。

本机完整测试 **469 项及 8 个子测试通过**，静态检查与 JavaScript 语法检查通过。离线测试覆盖分数校验、待批阅占位值、真实 0 分及只读列表请求；浏览器覆盖刷新按钮、五种成绩状态、过期错误提示和手机宽度布局。真实成绩取决于平台是否已经批阅并公布，演示分数不代表真实成绩。

冻结程序的演示启停、历史、独立子进程依赖检查与退出通过；安装器已编译并校验，打包界面文件与测试过的源码一致。
