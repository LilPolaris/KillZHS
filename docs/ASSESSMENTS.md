# 章节测验、考试与官方页面

版本：0.1.0-beta.7；协议调查日期：2026-10-17。

## 使用

1. 登录并同步共享课，在“AI 配置”保存平台 AI 或自定义服务并启用 AI。
2. 打开“测验与考试”，选择一门共享课并同步清单。同步不会进入试卷。
3. 勾选测验或在线考试，点击“自动答题并交卷”。这会进入试卷，可能消耗答题机会并启动考试计时。
4. 等待整卷生成、逐题保存、平台答案复核及一次交卷。结果和异常会出现在页面及按次任务日志中。

考试系统会单独检查登录。若提示凭据失效，请在工作台“学习概览”重新扫码登录后再同步，
只在官网浏览器登录不会更新脚本保存的登录凭据。章节测验和在线考试分别完成 CAS 登录。

该入口独立于学习任务，暂不加入定时计划。“学习任务跳过 AI 课程测验”不控制这里的主动答题。
答题使用任务开始时的 AI 配置和剩余请求上限，每题最多一次模型请求；不会主动重试生成。
试卷题目数超过剩余上限时停止。清单同步前无法保证知道真实题数，进入试卷仍可能已开始计时。

## 支持边界

- 本版接入共享课章节作业及普通在线考试的接口。校内课和特殊考试流程未接入。
- 自动处理纯文字单选、多选、判断题；图片、附件、特殊字形、复合题、填空和主观题停止并提示官网操作。
- 不伪造设备或人脸、短信验证结果。平台要求额外认证或锁定答题时停止。
- 所有题目先生成完成，才开始填写；不会为了交卷随机补空白答案。
- 保存成功还会读取平台已存答案，选项 ID 全部一致后才允许交卷。
- 交卷前持久化提交标记。网络超时、未知结果或进程中断后不再自动交卷，请在官网核对。
- “平台确认交卷”只表示接口返回明确的交卷状态，不代表答题正确、及格或成绩已发布。
- 尚无本版本真实账号的测验同步、模型答题、保存和交卷验收；离线测试不能代替平台实测。
- 已观察到一次真实同步卡在考试系统认证；只读登录检查未能通过现有凭据认证，尚无成功列表样本。

## 验证入口

三种方案的工程取舍：

|方案|优点|代价与限制|
|---|---|---|
|自动识别并通过|人工操作最少|当前点选验证码还需要识图、坐标、会话和结果确认；本版未实现|
|只搬验证码组件|界面集中|图片本身不足以完成验证，组件还依赖官方脚本、登录会话和挑战令牌；本版未实现|
|内嵌官方页面|保留官方页面的登录和验证流程|可能受嵌入策略、第三方 Cookie 和登录跳转限制；本版提供试验入口和新窗口回退|

匿名浏览器检查已经确认：当前课程入口可在本地工作台 iframe 中跳转并显示官方登录页。
这不证明真实登录、验证码点选、旧 worker 恢复都成功，不能把 iframe 的 load 事件当作验证通过。
页面关闭会移除 iframe；完成验证后暂停官方播放器，再回工作台确认。测验任务需要重新同步并核对状态。

## 代码结构

- `fucker.py`：原有课程、视频及平台基础请求。
- `killzhs_ai.py`：模型服务、PPT 转换；保留原有实现和版权。
- `killzhs_ai_exam.py`：平台 AI 课程测验流程。
- `killzhs_assessments.py`：共享课章节测验和在线考试，协议解析、答题与提交记录。
- `web/assessments.js` / `web/assessments.html`：测验清单及官方页面工作区。

拆分后 `fucker.py` 从 2412 行降至约 1590 行；原有公共类名保持可导入，便于命令行兼容。
以后独立维护该项目，不再以保持上游文件最小差异为重构约束，MIT 来源与版权声明仍保留。
