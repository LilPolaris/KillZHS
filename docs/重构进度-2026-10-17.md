## 6. 安装器与公开发布

按用户授权发布 [0.2.1 测试版](https://github.com/LilPolaris/KillZHS/releases/tag/v0.2.1)，同时提供简体中文安装包、免安装 ZIP 和 SHA256 校验文件。安装器可选择安装位置和是否创建桌面快捷方式，默认不创建；支持当前用户安装和卸载，保留 v2 用户数据。已实测两种快捷方式选择、安装后的进程检查和启停、卸载及数据保留。

发布代码保留远端旧历史，新源码正常推送到 main，没有覆盖旧版标签。补齐 Python 解释器和 PyInstaller bootloader 的完整许可证及例外条款；本机构建清单和验收 JSON 不作为公共构件上传。

云端首次 Python 3.12 检查指出：基准记录于 Python 3.14，requests 默认 Accept-Encoding 含标准库支持的 zstd，而 3.12 默认不含。现仅按实际 requests 能力适配这个默认值，显式平台压缩请求头、其他请求头和正文仍严格比较；五个新测试防止误放宽比较规则。此修改只影响测试比较，不改变已打包的程序。

本机完整测试最终为 **391 项通过、8 个子测试通过**，静态检查通过。[云端双版本检查](https://github.com/LilPolaris/KillZHS/actions/runs/39031339931) 中 Python 3.12、3.14 的完整测试、静态检查和浏览器检查均通过。真实平台学习时长、模型答题和交卷仍不属于本次离线 / 安装验收。
