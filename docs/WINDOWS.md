# KillZHS Windows 使用说明

1. 完整解压压缩包，保留 KillZHS.exe 旁边的 _internal 文件夹。
2. 双击 KillZHS.exe，默认浏览器会打开本地工作台。不需要安装 Python 或 Node.js。
3. 使用知到 App 扫码登录，勾选课程，点击开始学习。

后台控制窗口会最小化到任务栏，可通过它重新打开网页或退出程序。
关闭网页不会停止后台程序；关闭控制窗口或网页设置中的“退出并停止任务”会退出。

AI 课程可自动同步，也可手动填写课程 ID 和班级 ID。默认跳过测验。
在 AI 配置中选择平台 AI 或自定义服务，保存不会调用模型。
任务运行时也可以保存 AI 配置，新配置从下一次任务生效，不改变当前运行的设置。
自定义服务的“检查模型列表”只请求 /models，不发送课程或答题内容。
生成请求上限包含重试次数，不代表金额上限。PPT 处理需另外配置文件服务。

定时计划按电脑本地时间执行，所选课程共用总时长（默认 30 分钟）。
需要电脑开机联网、程序保持运行并记住登录状态。每天最多自动触发一次，
默认错过时间不补跑；可设置 1–720 分钟的补跑窗口，当天最多尝试一次，跨天不补跑。
有其他任务运行时跳过；运行中可修改或暂停未来计划，不影响当前任务。
登录状态不可用时先检查网络和同步课程，必要时重新扫码；共享课需要验证码时整批停止，请到官方页面手动验证。
本版本不会自动开机、唤醒电脑或安装开机启动项。

数据保存在 %LOCALAPPDATA%\KillZHS，升级时可以直接替换程序目录，用户数据保留。
API Key、Cookie 和通知密钥为本机私密文件，请勿分享用户数据目录。
会话日志在退出后清空；每次任务的脱敏日志会单独保存，重启后仍可在“运行日志 → 历史记录 → 查看日志”打开或下载。
保留最近 100 次任务日志，每次最多 2 MB；升级前的历史记录没有详细日志。意外退出后会标记上次任务为“意外中断”。
“已运行”表示本次脚本任务结束，实际课程完成情况以平台为准。

在“消息通知”选择 PushPlus 或 Bark，填写自己的接收端密钥并启用。
保存不会发送消息；“发送测试通知”会实际发送一条消息，手机送达情况以接收端为准。
可选择任务结束、需要验证、登录状态不可用、计划跳过等提醒，默认关闭。
通知失败不会阻塞任务，任务通知的发送结果也会写进当次日志；本版不额外探测登录有效期。
演示模式不连接推送服务，打包检查使用本机模拟服务，不代表真实手机送达已经验证。

更新后请先保存未提交的配置，通过页面或控制窗口退出旧程序，再打开新版。
仅关闭网页不会退出后台；界面侧栏显示当前实际运行的版本号。
