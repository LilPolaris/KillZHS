# Windows 使用说明

适用版本：KillZHS 0.2.1。支持 Windows 10 / 11 x64。

## 启动与退出

推荐下载安装包，按提示选择安装目录，并决定是否勾选“创建桌面快捷方式”。默认安装到当前用户的 `%LOCALAPPDATA%\Programs\KillZHS`，不需要管理员权限。安装完成后可从开始菜单启动。Windows 应用列表提供卸载入口，卸载不会删除 `%LOCALAPPDATA%\KillZHS\v2` 下的设置、凭据和交卷记录。

完整解压 ZIP 后双击 KillZHS.exe，不要单独移动 exe 或删除 `_internal`。程序打开浏览器中的本地工作台，后台控制窗口会最小化。关掉网页不会停止后台任务，可从控制窗口或“偏好设置 → 退出并停止任务”退出。

如果默认 8765 端口已被占用，可使用 `KillZHS.exe --port 8766`。同一个数据目录不能重复启动；第二次启动会尝试打开已运行实例。

## 首次使用

新版不读取旧版设置和登录状态。先扫码登录，再勾选课程并按需调整倍速、每门课程时限、整批总时长。保存 AI 和通知配置不会发送外部请求；模型连接检查只请求模型列表。

发布版数据位于 `%LOCALAPPDATA%\KillZHS\v2`，包含登录状态、密钥、设置、历史、日志、答案缓存与交卷记录。密钥只存在本机，页面只显示是否已配置。请不要把用户数据目录上传或分享。

## 学习任务与停止

整批时长按实际经过时间计算，含课程切换和网络等待。到时或点击停止后尝试保存未上报进度，最多等待 30 秒，仍未结束则终止进程。平台已经接收多少进度，以平台实际记录为准。

共享课遇到验证后会显示官网入口。完成验证、暂停官网播放器，再回到工作台重新开始剩余课程。实验模式通过同目录的“验证实验模式.bat”显式启用；实验只在用户确认后重发一次原请求，不能自动判断验证是否成功。

## AI、测验与考试

AI 课程默认跳过测验。需要答题时先配置 AI 并调整跳过测验开关。请求上限包括失败重试，不等同于金额预算。启用 PPT 处理后，相关课件会发送到所配置的文件服务。

共享课“测验与考试”页支持纯文字单选、多选、判断题。进入试卷可能消耗机会或开始计时，自动生成的答案可能错误。整卷生成后先保存、读取复核，再提交一次；交卷结果未知时保留记录并阻止重复提交。不要删除交卷记录后重复运行来绕过这个保护。真实交卷尚未完成本人验收。

## 计划、通知与日志

计划仅在电脑开机、网络及登录状态可用、程序运行时触发；不会自动开机或唤醒。同一天最多尝试一次，默认不补跑，可设置当天补跑窗口。验证待处理或其他任务运行时跳过，并记录原因。

通知默认关闭，支持 PushPlus / Bark。测试通知按钮才会实际发送测试消息。历史保留最近 100 次任务，每次详细日志最多 2 MB。意外退出后，下次启动会把未完成任务标成意外中断。

## 演示与检查

`KillZHS.exe --demo` 使用临时数据，不连接真实平台或模型。工作台“环境检查”会在独立子进程内检查运行依赖，但不会验证账号、网络可达性或平台业务结果。
